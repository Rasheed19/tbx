# tbx
Toolbox for various i/o operations built for my day-to-day needs.

## Installation
Via uv:
```
uv add https://github.com/Rasheed19/tbx.git
```

Via pip:
```
pip install https://github.com/Rasheed19/tbx.git
```

## Usage
To check all the commands available in tbx, run
```
tbx --help
```

To check help for any command you can run 
```
tbx COMMAND --help
```
